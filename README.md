# Android 课程作业 - 作业五

`Dev` 分支仅保存作业五，避免其他课程作业混入本次提交。

| 目录 | 内容 |
| --- | --- |
| `hw5` | RecyclerView 三张牌翻牌游戏 |

## 分支

- `main`：包含作业一至作业四的稳定版本。
- `Dev`：仅包含作业五。
- `feat/hw4-photo-card-game`：作业四功能分支。

## 运行

1. 使用 Android Studio 打开 `hw5` 目录。
2. 等待 Gradle 同步完成。
3. 选择 `app` 配置并运行。

各工程只提交源码、资源、Gradle 配置和 Wrapper。`build`、`.gradle`、`.idea`、`local.properties` 以及签名文件均不纳入版本控制。
