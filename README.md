# Android 课程作业

本仓库按作业编号保存相互独立的 Android Studio 工程，每份作业都可以单独打开和运行。

| 目录 | 内容 |
| --- | --- |
| `hw1` | 第一次作业 |
| `hw2` | MVC 实验 |
| `hw3` | 多 Activity 实验 |
| `hw4` | 照片扑克牌翻牌游戏 |
| `hw5` | RecyclerView 三张牌翻牌游戏 |

## 分支

- `main`：稳定版本。
- `Dev`：作业五开发分支。
- `feat/hw4-photo-card-game`：作业四功能分支。

## 运行

1. 使用 Android Studio 打开 `hw1` 至 `hw5` 中对应的目录。
2. 等待 Gradle 同步完成。
3. 选择 `app` 配置并运行。

各工程只提交源码、资源、Gradle 配置和 Wrapper。`build`、`.gradle`、`.idea`、`local.properties` 以及签名文件均不纳入版本控制。
