# 作业四：照片扑克牌游戏

应用标题：毕美灵2024110101。使用 Kotlin、XML Views 和 MVC，包含三个 Activity。

## 功能
- 首页显示姓名、性别、学号、电话、邮箱、爱好和最高分。
- 修改信息支持保存、取消、性别单选、爱好多选、从相册选择头像。
- 4×4 扑克牌牌阵，13个照片资源按发送顺序对应 A～K，保留花色点数。
- 使用老师附件的随机抽牌与匹配规则：点数相同基础分4，花色相同基础分1；匹配奖励为基础分×4，每次翻开扣1分，不匹配另扣2分。
- 匹配失败时先前牌盖回、新牌保持翻开；再次点未匹配的明牌可盖回且不扣分。
- 重置、退出、系统返回、已匹配牌禁用、全部匹配及无可匹配牌提示。
- 最高分取每次游戏页面中达到的最高分，重置不清除该最高分；返回首页时更新。
- 页面重建保存当前表单、牌局和分数。按作业要求，信息不写入文件；彻底结束进程后不保证保留。

## 打开与运行
使用 Android Studio 打开项目根目录，等待 Gradle 同步，选择 app 后运行。沿用原项目 SDK 和依赖版本。
需要安装原项目的 Android API 37 SDK。local.properties 是本机 SDK 路径，不应提交 Git。

## MVC
- Model：model/Card、Deck、CardMatchingGame，保留教师核心匹配算法。
- View：res/layout 三个页面及 GameActivity 创建的牌面控件。
- Controller：MainActivity、EditProfileActivity、GameActivity。
- 新增模型能力：只读花色点数、可注入牌组以便测试、序列化状态、可匹配性判断。

## 手动验收
1. 首页打开修改页，填写资料、选择性别爱好并保存，检查首页全部更新。
2. 再次修改后取消，检查首页保持已保存数据。
3. 点击游戏第一张牌应得 -1 分，牌面显示照片和花色点数。
4. 按相同点数/花色规则检查配对；已匹配牌不可再点。
5. 重新开始应重置当前分数和牌阵；退出后首页最高分更新。
6. 旋转屏幕后，个人信息和当前游戏牌局应保留。
7. 选择头像后保存和取消分别验证。
